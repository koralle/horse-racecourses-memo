## コース

| 用語 | 意味 |
| --- | --- |
| 直線 | 最後のコーナーを回ってからゴールまでの区間。長いほど差しが決まりやすい |
| 内回り・外回り | 同じ競馬場にある 2 つの周回コース。外回りのほうが 1 周が長い |
| A コース・B コース | 芝の傷みに応じて仮柵を動かした状態。A が最も内側 |
| 淀の坂 | 京都競馬場の 3〜4 コーナーにある下り坂 |
| 急坂 | 中山・阪神の直線にある上り。スタミナを要求する |

## 枠と脚質

| 用語 | 意味 |
| --- | --- |
| 枠順 | 出走馬に割り当てられるゲートの位置。1〜8 枠 |
| 逃げ | 先頭で走る戦法 |
| 先行 | 2〜4 番手あたりで運ぶ戦法 |
| 差し | 中団で構えて直線で伸びる戦法 |
| 追い込み | 後方から直線だけで伸びる戦法 |

## 開催と馬場

| 用語 | 意味 |
| --- | --- |
| 開催 | 同じ競馬場で数日続けてレースを行う単位 |
| 馬場状態 | 良・稍重・重・不良。含水率で決まる |
| 含水率 | 芝・ダートの水分量。高いほど時計がかかる |
| クッション値 | 芝の反発力。高いほど速い時計が出やすい |

## 施設

| 用語 | 意味 |
| --- | --- |
| パドック | レース前に馬が周回する場所 |
| 地下馬道 | パドックから本馬場へ向かう通路 |
| 検量室 | 騎手の体重を測る部屋 |
| ウイナーズサークル | レース後に勝馬が記念撮影する場所 |
