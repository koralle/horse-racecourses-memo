## ページを足す

距離ページは `src/data/courses.json` から生成する。手で MDX を書く必要はない。

1. `courses.json` の該当会場に距離を足す（`sources` は必須）
2. `pnpm gen:courses` を実行
3. `pnpm lint:docs` と `pnpm build` で確認
