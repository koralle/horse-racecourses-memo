JRA が馬券を発売する海外競馬のうち、2026年の指定競走が行われる会場を国別に並べる。対象は 31 会場・116 競走。

| 国・地域 | 会場 |
| --- | --- |
| アラブ首長国連邦 | [メイダン](/racecourses/overseas/maidan/) |
| サウジアラビア | [キングアブドゥルアジーズ](/racecourses/overseas/king-abdulaziz/) |
| 香港 | [シャティン](/racecourses/overseas/sha-tin/) |
| アメリカ合衆国 | [キーンランド](/racecourses/overseas/keeneland/)、[コロニアルダウンズ](/racecourses/overseas/colonial-downs/)、[サラトガ](/racecourses/overseas/saratoga/)、[チャーチルダウンズ](/racecourses/overseas/churchill-downs/)、[デルマー](/racecourses/overseas/del-mar/)、[ベルモントパーク](/racecourses/overseas/belmont-park/)、[ローレルパーク](/racecourses/overseas/laurel-park/) |
| イギリス | [アスコット](/racecourses/overseas/ascot/)、[エプソム](/racecourses/overseas/epsom/)、[グッドウッド](/racecourses/overseas/goodwood/)、[サンダウン](/racecourses/overseas/sandown/)、[ドンカスター](/racecourses/overseas/doncaster/)、[ニューベリー](/racecourses/overseas/newbury/)、[ニューマーケット](/racecourses/overseas/newmarket/)、[ヨーク](/racecourses/overseas/york/) |

| フランス | [サンクルー](/racecourses/overseas/saint-cloud/)、[シャンティイ](/racecourses/overseas/chantilly/)、[ドーヴィル](/racecourses/overseas/deauville/)、[パリロンシャン](/racecourses/overseas/parislongchamp/) |
| オーストラリア | [コーフィールド](/racecourses/overseas/caulfield/)、[フレミントン](/racecourses/overseas/flemington/)、[ランドウィック](/racecourses/overseas/randwick/)、[ローズヒルガーデンズ](/racecourses/overseas/rosehill-gardens/) |

<Aside type="note" title="発売の条件">
  指定競走のうち、農林水産大臣の認可を受けた競走が対象。実際の発売は日本馬の出走予定がある場合に限られる。
</Aside>
